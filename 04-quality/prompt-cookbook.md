# Prompt Examples & Patterns (Cookbook)

## Minimum acceptable prompt
```
1girl, looking at viewer, smile, outdoors, masterpiece, high score, great score, absurdres
```

## Generic nighttime portrait
```
1girl, solo, looking at viewer, smile, night, outdoors, city lights, depth of field, anime coloring,
masterpiece, high score, great score, absurdres
```

## Cosplay (avoid confusion)
```
1girl, (character A), (series A), cosplay, (character B outfit), looking at viewer, smile, outdoors, night,
masterpiece, high score, great score, absurdres
```

## Anti-patterns
❌ Too short:
```
girl, anime
```

❌ Quality tags in the middle (they will be moved to the end):
```
1girl, masterpiece, smile, outdoors, absurdres, looking at viewer
```

❌ Contradiction:
```
solo, 2girls
```

## Quick tips
- Use `solo` when referring to a single person.
- Anchor the scene with environment tags (`indoors/outdoors`, `night/day`).
- Keep quality tags at the end.
